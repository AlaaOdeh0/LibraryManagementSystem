# Library Management System

This is a simple Java-based Library Management System built using **Object-Oriented Programming (OOP)** principles in Eclipse.


## ✨ Features

- Add and manage different types of library items:
  - Books
  - Magazines
  - Videos
  - Archived Documents
- Borrow and return items
- Display item status
- Search items by title
- Demonstrates OOP concepts:
  - Abstraction
  - Inheritance
  - Polymorphism
  - Encapsulation


## 🛠 Technologies Used

- Java
- Eclipse IDE
- Git & GitHub


## 🚀 How to Run

1. Clone the repository
2. Open the project in **Eclipse** as a Java project.
3. Run the `LibraryApp.java` (or your main class).
